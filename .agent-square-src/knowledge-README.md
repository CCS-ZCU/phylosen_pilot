# Shared knowledge

Store stable, reusable, non-secret knowledge here. Keep current project checkpoints in
the corresponding repository (for example `docs/agent/RUN_STATE.md`) so that they travel
with the project.

Client-owned automatic memory remains in its native directory. This directory is not a
replacement for `~/.claude/memory`, Codex memories, or OpenCode state until an explicit,
reviewed migration is performed.
